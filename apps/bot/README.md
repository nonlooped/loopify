## Setup

1. Install dependencies with `pnpm install`.
2. Rename `.env.example` to `.env`.
3. Fill in your Discord credentials in `.env`.
4. Start the bot with `pnpm run dev`.

## ForgeLoop

## Command Sync

Commands sync automatically on startup.

- Development defaults to guild sync and requires `GUILD_ID`
- Production defaults to global sync when `NODE_ENV=production`
- Manual deploy: `pnpm forgeloop commands deploy --guild` (or `--global` for global commands)
